# Psyche: from island to civilization

A plan for growing Psyche from five minds on Kettle Island and one builder on Tern Holm into a self-running civilization of hundreds to thousands of minds, with an analysis layer that lets you trace why anyone does anything, and a cost design that fits the whole journey inside about $1000 of Anthropic API credit.

Status: plan only, no code. Written 2026-10-30.

## Where we are

| Built | What it gives us |
| --- | --- |
| **M0 Specimen** (PR #1) | The mind engine: ACT-R memory with reconsolidation, appraisal and OCC emotions, a four-slot global workspace, System 1 and 2 decisions, sleep and trait drift. Every cycle writes a `Trace`; the brain scan reads only traces. Offline mock faculties. |
| **Kettle Island** (PR #2) | Five minds on a clock, routines, encounters, gossip with rumor lineage, event injection, event-sourced sessions with exact replay and rewind. |
| **Founders F0** (PR #3) | A voxel islet, a blueprint language, the Architect faculty, a body layer that gathers and builds block by block, a Three.js view. |

Three things in the current code matter for what follows:

1. **Provenance already exists in pieces.** `Source.ref`, `Belief.evidence`, `Belief.rumor`, `MemoryVersion.changes`, `Contribution.ref` and `DecisionTrace.because` each record one link of "this came from that". Nothing yet joins them into one graph that spans time and people. That join is the analysis layer.
2. **Every faculty defaults to `claude-opus-5-5`.** Fine for five minds; ruinous for a thousand. Model tiering is the first change.
3. **Perceive is an LLM call on every percept.** Most percepts in the world are generated by the engine and are already structured. Only free text (your messages, LLM-written speech) needs the model to perceive it.

## The shape of the end state

A world that runs for weeks of real time and centuries of sim time. Settlements founded by the first families, built from voxels by their own hands, with trades, norms, councils, feuds, myths and children who inherit their parents' stories in distorted form. You can watch from far away (population maps, the spread of a belief, a time-lapse of a town growing) or zoom into one person and open their head. And at any point you can ask *why*, and follow the answer back through memories, conversations and other people's minds to the events that started it.

The architecture does not change: a deterministic, event-sourced engine owns all psychology and all world state, and the language model is a narrow faculty called only where language or genuinely novel judgment is needed. What changes is scale, which forces three new systems: the **causal ledger** (analysis), the **budget governor** (cost), and **level-of-detail simulation** (scale).

## 1. The analysis layer

The brain scan answers "what was in this head at this moment". The analysis layer answers three bigger questions:

- **Why did she do that?** Follow a decision backwards to its causes.
- **Where did this fear come from?** Trace a belief, fear or grudge to the events that planted it, the moments that fed it, and the people who passed it on.
- **What is it doing now?** Follow a belief or memory forwards to every decision it has bent since.

And it answers them across time (decades of one life) and across agents (a fear that started in one person and is now held by half a town).

### 1.1 The causal ledger

One append-only store of typed nodes and weighted edges, written by the engine as a side effect of the mechanisms that already run. Nothing in the ledger causes behavior; it records what the mechanisms did, the same rule `explain.ts` follows today.

**Nodes** (each with tick, agent, and a pointer into state):

| Node | Written when |
| --- | --- |
| `event` | Something happens in the world: a storm, a catch, a fall, a house finished |
| `percept` | An agent perceives an event or an utterance |
| `episode` / `episode-version` | A memory is encoded, or rewritten on recall |
| `belief` / `belief-version` | A belief forms, strengthens, weakens or is overwritten |
| `schema` | A core belief is installed by a formative event (where fears live) |
| `emotion` | An emotion crosses a threshold |
| `relation` | Trust or liking shifts by more than a set amount |
| `trait-drift` | Nightly drift moves a trait |
| `goal` | A goal is adopted, invested in, dropped |
| `decision` | A choice is made (links to its full `Trace`) |
| `utterance` | Someone says something to someone |
| `norm` / `institution` / `artifact` | Later phases: a rule, a council, a written record, a building |

**Edges** carry a mechanism name and a weight, so every link says how and how much:

| Edge | Example |
| --- | --- |
| `encoded-from` | episode ← percept ← event |
| `told-by` | belief ← utterance ← teller's belief (rumor lineage, across minds) |
| `rewritten-by` | episode-version ← misinformation from a belief, or mood at recall |
| `consolidated-from` | belief or schema ← sleep replay of episodes |
| `appraised-with` | emotion ← percept, adjusted by trust, schema, trait (the existing `adjustments`) |
| `in-workspace` | decision ← memory, belief, feeling, goal that won a slot, weighted by its share of utility (the existing `because` and option `terms`) |
| `suppressed` | decision ← items that competed and lost (the existing `subliminal`), so you can see what she did not think of |
| `shifted` | relation or trait-drift ← the decisions and events that moved it |

Most of these are a line or two at the point where the engine already computes the number. The work is plumbing, not new psychology.

**Storage.** SQLite (`better-sqlite3`) in the server, one file per world, written in batches per sim hour. Volume estimate: about 60 edges per focused agent per sim day, about 10 for background agents. A town of 150 for a sim year is roughly 1.5 million edges, which SQLite handles comfortably. For century runs, old low-weight edges are rolled up into summary edges ("47 small slights from Corran over 1203 to 1208") while every edge on a path to a schema, a strong belief or a major decision is kept verbatim.

### 1.2 Queries

| Query | How it works |
| --- | --- |
| **Why** (backward slice) | From a decision, walk incoming edges by weight, depth-limited, and return the top paths to root events. "Mara refused Theo's boat because the storm-night memory (rewritten twice, once by Jun's rumor) took a workspace slot and low benevolence trust doubled its blame." |
| **Genealogy** of a fear or belief | From a schema or belief, collect every version, every reinforcing episode, every teller, every sleep consolidation. Shows the formative moment, how it grew, who fed it. |
| **Influence** (forward slice) | From any node, the decisions it reached and how much it moved each one. "The fear of open water has been in her workspace for 212 decisions and changed the outcome of 31." |
| **Spread** (cross-agent) | For a belief lineage (`rumor` id generalized to any idea), the transmission tree across people, with mutation at each hop and belief strength in each holder. The phylogeny of an idea. |
| **Divergence** | Where a person's memory now disagrees with what actually happened (`original` vs `value` per detail slot, already stored), and which edges caused each change. |
| **Says vs was** | Ask an agent why they did something. The Speak faculty answers in character from what they can access. The ledger shows what actually drove it. The gap is confabulation, and it is one of the most human things the system can show. |
| **Counterfactual** | Fork the world at a snapshot, remove one node (an event, a memory, a rumor), replay deterministically, and diff. Because sessions are already seed plus inputs plus recorded calls, the fork reuses every recorded LLM response until the timelines diverge, so most of a counterfactual is free. |

Edge weights give an approximate attribution. Counterfactual replay gives the real one, and is used to confirm the top few causes of anything you pin.

### 1.3 Views

- **Lineage graph.** A left-to-right timeline DAG from root events to the selected decision or belief. Nodes colored by kind, edges by mechanism, thickness by weight. Click any node to open the brain scan at that tick.
- **"Ask why" box.** Plain questions ("why does Wren never go to the harbour?") are answered by running the right query and having a Sonnet-tier Narrator write the answer from the returned paths only, citing nodes. The answer is a rendering of the graph, never a guess.
- **Fear and belief atlas.** For a town: which fears and core beliefs exist, how many hold each, where each came from, how it is trending.
- **Idea phylogeny.** Spread trees for stories, myths and norms across generations.
- **Diff two worlds.** Side-by-side of a world and its counterfactual fork, with the first point of divergence and the cascade that followed.

### 1.4 Building it in steps

1. Ledger schema and writes from existing traces (no new mechanisms). Why and Genealogy queries. Lineage view on Kettle Island.
2. Cross-agent edges (utterance and told-by), Spread query, Divergence, Says vs was.
3. Counterfactual forks with recorded-call reuse.
4. Roll-ups, atlas and phylogeny views for big populations.

## 2. Cost design

### 2.1 Prices this plan uses

From the current Anthropic price list (per million tokens, input / output; cache reads are about a tenth of input; the Batch API is half price):

| Model | Input | Output | Role here |
| --- | --- | --- | --- |
| `claude-haiku-5-5` | $0.10 | $0.50 | Default for everything: speech, perceiving free text, dreams, memory reconstruction |
| `claude-sonnet-5-5` | $2.00 | $10.00 | System 2 deliberation on high-stakes choices, the Narrator, the Architect for anything bigger than a hut |
| `claude-opus-5-5` | $4.00 | $20.00 | Rare: founding a town plan, writing a law, the Chronicle. Off by default |

Haiku 5.5 is twenty times cheaper than Sonnet on input. That ratio is the whole budget strategy.

### 2.2 Rules first, model second

The model is only called where language or novel judgment is needed. Everything else is engine:

| Engine only (no tokens) | Model call |
| --- | --- |
| Routines, movement, work, eating, sleeping | Speech the user can see, in salient moments |
| Gathering and placing blocks from a blueprint | Perceiving free text (your messages, LLM speech) |
| Percepts from engine events (already structured) | System 2 deliberation when conflict, novelty and stakes are high |
| Greetings, small talk, routine trades (templates) | A new blueprint (Architect) |
| Conversation outcomes in the background (rolled from state) | Nightly dream for focused agents |
| All appraisal, memory, trust, drift, sleep | Narrator answers in the analysis layer |

Two big wins in today's code: Perceive is skipped for engine-generated percepts, and speech below a salience threshold uses the existing template renderer.

**Lazy narration.** Background conversations are resolved by the engine and written to the ledger as structured exchanges with no text. If you open one later, Haiku renders it on demand from the stored structure. You pay for words only when someone reads them, and the analysis layer still works on every agent because it reads structure, not text.

### 2.3 Level of detail

| Tier | Who | Tick | Model use |
| --- | --- | --- | --- |
| **L0 Focus** | Whoever you are watching, plus anyone in a high-salience event (a death, a fight, a council vote) | Every sim minute | Haiku speech, Sonnet deliberation when System 2 engages |
| **L1 Active** | Everyone in the settlement you are viewing | Every sim minute | Haiku only, salient moments only |
| **L2 Background** | Other settlements | Every sim hour | None. Engine-only, outcomes rolled, ledger still written |
| **L3 Aggregate** | Distant or ancient populations (C4) | Every sim day | None. Distributions of mood, belief prevalence, skills; individuals materialized from the distributions when you zoom in |

Promotion is instant and seamless because every tier runs the same engine state; only the cadence and the faculties change. Demotion happens after a cooldown.

### 2.4 Caching, batching, replay

- **Prompt caching.** Faculty instructions and the agent's stable identity come first in every request (already done in `claude.ts`). Grouping calls by agent keeps the prefix warm. Watch `usage.cache_read_input_tokens` in the meter; zero means a silent invalidator.
- **Batch API at half price** for anything not on screen: nightly dreams and consolidation narratives, the Chronicle, background renders. In headless fast-forward runs the world pauses at the day boundary until the batch returns.
- **Response memo.** Template-like calls (a greeting in a given style between two people with a given relation) are memoized by a hash of the compact request. Many hits in a large world.
- **Recorded calls.** Sessions already store every faculty response. Replays, rewinds and counterfactual forks reuse them for free until the timeline diverges.

### 2.5 Budget governor and cost meter

Every faculty call goes through one gate in `packages/faculties`:

- **Price table and usage accounting** from `response.usage` (input, cached, output), per call, tagged by faculty, agent, tier, world and phase.
- **Daily cap** (default $10, set with `PSYCHE_DAILY_CAP`) and a **per-world cap**. Approaching the cap, the governor degrades gracefully instead of stopping: Sonnet calls drop to Haiku at 80%, salience thresholds rise at 90%, and at 100% everything switches to the offline mock while the world keeps running.
- **Live cost meter** in the UI: spend today, spend this world, dollars per sim day, a projection to the end of the run, and a breakdown by faculty. A terminal version prints with `npm run island` and headless runs.
- **Offline mock mode** stays the default with no key, and becomes a first-class run mode for development and tests (`PSYCHE_FACULTIES=mock`). Every phase is built and tested in mock before a single paid run.

### 2.6 What things cost

Per-agent estimates per sim day, using the prices above with typical prompt sizes from the current faculties (about 3k input tokens, mostly cached, and 150 to 800 output tokens):

| Tier | Calls per sim day | Cost per agent per sim day |
| --- | --- | --- |
| L0 Focus | ~12 Haiku speech, ~2 Sonnet deliberations, 1 dream | ~$0.03 |
| L1 Active | ~4 Haiku speech, 1 batched dream | ~$0.002 |
| L2 Background | None live; a few lazy renders if opened | ~$0.0002 |
| L3 Aggregate | None | ~$0 |

Example worlds:

| World | Mix | Per sim day | A sim year |
| --- | --- | --- | --- |
| Village of 20 | 5 L0, 15 L1 | ~$0.18 | ~$65 |
| Town of 150 | 10 L0, 60 L1, 80 L2 | ~$0.45 | ~$165 |
| Region of 1000 | 15 L0, 150 L1, 835 L2 | ~$0.90 | ~$330 |
| Civilization of 5000 | 20 L0, 200 L1, 1000 L2, rest L3 | ~$1.20 | ~$440 |
| Any size, headless (nobody watching) | Everyone L2 or L3; only the year's top historic moments rendered, in batch | ~$0.0003 | ~$0.10 |

Spend grows with what you watch, not with how many minds exist. A sim year of a thousand people costs only about twice a sim year of a town, because only the window you look through is rendered in language. Unwatched runs are nearly free: the engine runs every mind with no tokens, the ledger is still written, and only the handful of moments that matter most each sim year (a death, a founding, a war) are rendered by Haiku in batch, plus one Sonnet chapter of the Chronicle. That is what makes a sim century affordable: about $10 headless, with watched stretches paid at the rates above.

These numbers are estimates until the meter measures them in C0. The first paid run of each phase is a short calibration run, and the plan is re-cut if real cost is more than 1.5 times the estimate.

## 3. Milestones

Each phase ends with something you can watch and something you can analyze. Build times assume steady work in sessions like the ones so far; they are rough.

### C0 Foundations (1 to 2 weeks, ~$15)

Make scale and analysis possible before adding anything to the world.

- Model tiering per faculty, Haiku by default. Perceive skipped for engine percepts. Template speech below salience.
- Budget governor, daily cap, live cost meter, calibration harness that reports real dollars per agent per sim day.
- Causal ledger v1 from existing traces. Why and Genealogy queries. Lineage view on Kettle Island.
- Merge the island and Founders worlds into one world model (the voxel terrain becomes the island; the five live there).
- **Done when:** Kettle Island runs a sim week on real Claude for under $1, and you can click Mara's fear of the storm and see where it came from.

### C1 Village (2 to 3 weeks, ~$70)

Founders F1 to F2 and the island's next steps, together.

- 12 to 20 founders land on a larger island and build a village: homes, a shared store, a jetty. Group builds with shared blueprints.
- Food and shelter as light survival pressure. Seasons. Weather.
- Overhearing, conversations of three or more, families and households.
- Analysis: cross-agent edges, Spread, Divergence, Says vs was.
- **Done when:** a village stands that nobody scripted, and you can trace a grudge from one person's misremembered night through gossip into who refuses to help build whose house.

### C2 Town and generations (3 to 4 weeks, ~$160)

- 50 to 150 agents. Aging, pairing, births and deaths. Children start with temperament from their parents and learn their beliefs from stories, which means distorted inheritance.
- Roles and skills (fisher, builder, healer, trader) that emerge from aptitude and need. Simple barter economy.
- Norms: repeated sanctions harden into expectations (Bicchieri), stored as `norm` nodes.
- LOD tiers L0 to L2 and the promotion rules.
- Analysis: Influence query, counterfactual forks, fear and belief atlas.
- **Done when:** a second generation holds a fear none of them experienced first-hand, and the atlas shows which grandparent's storm it came from.

### C3 Settlements and culture (4 to 6 weeks, ~$260)

- 300 to 1000 agents across several settlements. Migration and founding of new settlements by splinter groups.
- Institutions: councils, elected or inherited leaders, laws as written artifacts (Opus or Sonnet writes the text; the engine enforces it).
- Myth and religion from shared memories distorted across generations; ritual as habit plus norm.
- Trade between settlements, scarcity, conflict and reconciliation.
- Analysis: idea phylogeny, the Chronicle (a batch-written history of the world built from the ledger), population dashboards.
- **Done when:** two towns have different stories about the same founding event, and you can show exactly where the versions split.

### C4 Civilization (6 to 8 weeks, ~$300 including a long run)

- 1000 to 5000 agents. L3 aggregate tier for distant populations with materialization on zoom.
- Writing and records that outlive their authors and can be misread. Knowledge and technology that spread by teaching and get lost when the teachers die.
- Headless server mode: the world runs for days or weeks on its own with a daily cap, snapshots, and a morning digest of what happened.
- Time-lapse view of settlements growing over centuries.
- **Done when:** a world has run for a sim century on its own and the analysis layer can explain a war, a schism or a migration from its first causes.

### Budget across phases

| Phase | Estimate |
| --- | --- |
| C0 Foundations | $15 |
| C1 Village | $70 |
| C2 Town and generations | $160 |
| C3 Settlements and culture | $260 |
| C4 Civilization | $300 |
| Reserve (re-runs, calibration misses, demos) | $195 |
| **Total** | **$1000** |

Most of each phase's spend is long showcase runs, not development; development runs on the mock. At the default $10 daily cap no single day can burn more than one percent of the budget.

Total build time: roughly 16 to 23 weeks.

## 4. Risks

- **Cost estimates are guesses until C0 measures them.** The governor caps the damage and the calibration gate re-cuts the plan before money is spent at scale.
- **Haiku speech quality.** If Haiku sounds flat in L0, L0 speech moves to Sonnet for named characters only; about $0.10 per L0 agent per sim day, still inside the plan if L0 stays small.
- **Emergence may need tuning.** Big populations can settle into dull equilibria. The experiments lab (ablations, seeds, counterfactuals) is how we find which mechanisms matter, and the ledger makes it visible when nothing is happening and why.
- **Ledger size on century runs.** Roll-ups keep it bounded; worst case the oldest centuries move to aggregate summaries.
- **Determinism across tiers.** Promotion and demotion must not change outcomes that are already written. Tests replay the same world at different viewing patterns and check the ledger matches at L1 and below.

## 5. Decisions for Bryce

1. **Start C0 now?** Recommended. It is cheap, it makes every later phase measurable, and it delivers the first version of the analysis layer on the island you already have.
2. **One world or two.** Recommended: merge Kettle Island and Founders into one voxel world in C0, so the civilization grows from the characters you already know.
3. **Daily cap.** Recommended $10 per day default, adjustable.
4. **Generations in C2.** Recommended yes. Inherited, distorted beliefs are where the analysis layer gets most interesting.
